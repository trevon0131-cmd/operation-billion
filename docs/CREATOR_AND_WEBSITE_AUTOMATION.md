# OPERATION BILLION v0.7 — Creator, video and website operating guide

## What this build is, and what it is not

The cumulative upgrade retains **29 product/service specialists** and expands the **opportunity research library to 39 distinct income-method templates**. The new Creator & Website Wing contains two **actual built-in offline builders**: (1) original vertical/landscape video **storyboards, PNG slide images, timed SRT captions, scripts, and optional MP4 rendering with locally installed FFmpeg**, and (2) complete responsive HTML/CSS **demonstration websites** with service proposals and **UNSENT** email drafts. The existing Google Trends RSS, GitHub search, Hacker News and local Ollama connector remain available. The new research directory documents optional third-party open-source programs, but **does not execute downloaded repositories or secretly install anything**.

**Not finished:** automatic TikTok/YouTube channel setup, monetization eligibility, publishing, Gmail sending, live audience analytics, website hosting, domain registration, payments and verified orders. An approved court decision means **permission to create a local draft**, not permission to spend money, post to an account, contact a person or claim sales. The billion-dollar counter is aspirational, not a profit forecast.

## 1. Automatic research and business-selection loop

During each live autopilot cycle, the existing public-signal services collect:

- **Google Trends Trending Now RSS** — cached, bounded, and filtered. Trending searches are observations about search interest, not evidence that an audience will buy.
- **GitHub repository metadata** — repository name, description and source URL via public API. Rotation now also looks for video-editing, text-to-speech, site generation and subtitle projects. Repositories are not automatically cloned or executed. Popularity is not a business viability metric.
- **Hacker News and GitHub Blog** — public discussions and software news, used as weak research leads.
- The **39-method hypothesis catalogue** — an original market-research framework that gives each candidate a target customer, deliverable, no-spend trial, channel and prerequisites.

The Trend Engine reviews approved research cases and produces local startup plans with five steps, sample deliverables where its existing builders apply, risk checklists and 7/14-day validation plans. The new Creator & Website Wing reads recent, previously stored Google Trends sources to identify useful themes **only when they match** safe predefined educational topics; otherwise it transparently uses an evergreen useful topic. There is **no guarantee** a trend is profitable, and no ordinary Google Search scraping.

The central deterministic AI Court checks proposals for zero spend, IP/rights, action permission, delivery feasibility, truthful claims, and nondeceptive products. It logs prosecutor, defense, expert witnesses, five jury votes and the judge. GUILTY action cannot execute; existing repair/pivot managers seek a compliant alternative or different method. When a trial is actually launched, existing lifecycle checks track evidence reported by the owner: 7-day review (>=100 actual views and zero clicks) and 14-day review; unlaunched is not considered a market failure. **Reported metrics are labeled unverified** until the relevant authorized analytics connector exists.

## 2. Built-in video and YouTube/TikTok workflow

What *works now without any paid dependency*:

1. Pick an original useful topic (either matched to current saved Trends evidence or rotated evergreen ideas). Do not copy viral creators' scripts, music, films or recognizable characters.
2. Ask the court for permission to generate a **local** draft; log approved or rejected result.
3. Produce five original PNG slides, an accessible `captions.srt`, a `script.txt`, `metadata.json` and `README.txt`. Short format: 540x960 portrait, longer format: 960x540 landscape. The files are valid images and can be opened without AI subscriptions or a GPU.
4. If **FFmpeg** is installed, the autonomous worker attempts a short, silent MP4 using its original slides. FFmpeg is not installed or downloaded by this upgrade; if missing, keep the scene images and instructions. Video images are **static text slides**, not a fully generative cinematic video. MP4 output has **no synthesized voice or soundtrack** in this release.
5. If the user has explicitly enabled `OPERATION_BILLION_LOCAL_AI=1`, the farm tries an **Ollama** text model only on `127.0.0.1` for five alternative scene headings, rejecting invalid output and falling back to tested curated scenes. It **does not download** Ollama or models. AI suggestions still require human fact-checking. The local content model is not itself a real-time web browser.
6. Stage quality checks (facts, legibility, uniqueness, accessibility, audio/stock-media rights and applicable AI-content disclosures). Platform uploading and credentials **are not connected**.
7. Test *only after actual authorized publication* using genuine YouTube/TikTok creator analytics: views, retention, clicks, subscribers and relevant conversions. Do not invent results. Review after 7/14 days, but permit extra time for algorithmic discovery and do not abandon a useful niche solely because a small sample did not go viral.

**What can be added separately later:** Piper text-to-speech, Whisper.cpp transcription (with permissions), ComfyUI image/video model generation (capability depends on GPU/RAM and model licenses), MoneyPrinterTurbo as a separately audited video pipeline, MoviePy, stock footage from licensed sources, and YouTube Data API with an authorized key. These are **NOT installed or integrated** in v0.7. Some 'free AI' websites offer limited free credits, subscriptions or noncommercial terms; this project will not treat them as unrestricted commercial services.

Commands from the existing VS Code folder:

```powershell
py -3 -m botfarm toolbox
py -3 -m botfarm video-demo --topic "Organize a job search" --format short
py -3 -m botfarm video-demo --topic "Create an educational short" --format short --render
py -3 -m botfarm video-demo --topic "Make a simple budget" --format youtube --render
# OPTIONAL only if Ollama is already installed and local model is available:
py -3 -m botfarm video-demo --topic "Plan a weekly routine" --ai --render
```

Use `--render` to attempt MP4, but a PNG/SRT draft remains available if FFmpeg isn't installed. The project tests MP4 rendering when FFmpeg is present in the build environment; it may not be installed on your laptop.

## 3. Website factory and B2B web design workflow

The new website factory creates a **genuinely openable, mobile-responsive local `index.html`** from original HTML/CSS for a *fictional demonstration business*. It includes a headline, services, About and Contact sections, responsive styles, keyboard-focus treatments, clear 'FICTIONAL DEMO' markers, and **no contact forms or payment scripts**. It also generates:

- `proposal_DRAFT.txt`: scoped deliverables, what the client must approve, truthful pricing/hosting disclaimers and actual validation milestones.
- `outreach_UNSENT.txt`: a commercial email draft; placeholders for verified real contact and business details, your actual postal contact information, opt-out method, and transparent advertising identification. **This file is never emailed** by the bot.
- `CHECKLIST.txt`: contact info verification, mobile tests, accessibility and hosting terms.

You can offer pages for barbers, cafes, tutors, plumbers, cleaners, nonprofits, fitness coaches, creators, and other legitimate service providers. **Do not use a real business name or its trademarks to imply that you have a contract**; rename the fictional demo only after the client approves a project. Do not fabricate testimonials, credentials, years of experience, customer counts or measurable site improvements.

A compliant business acquisition process is:

1. Research a business from its own public website or **authorized/permissioned** source, avoiding Google Maps bulk extraction and deceptive automation. Existing `lead-add` and opt-in `business-review` handle user-supplied businesses; the farm does not currently discover and email arbitrary owners automatically.
2. Produce an original sample or public performance assessment where site terms permit. Give the owner a clear service scope and quotation; avoid implying you scanned the target site when you didn't.
3. Prepare a truthful personalized email. In the U.S., **CAN-SPAM applies to business-to-business promotional email**: accurate headers and subject, clear promotional identification, working opt-out, valid postal address, and honor opt-out requests. Check applicable local and international law. Don't bulk-send to harvested addresses.
4. You must review and authorize each external communication and client agreement. Client identity, content ownership, hosting, domain, price, revisions, handoff and post-launch support need real agreement.
5. After permission and a suitable hosting provider, deploy an approved website and record **real replies, booked consultations and paid invoices**. The current core **does not deploy**.
6. Retire unlaunched plans after 14 days (categorized as unlaunched, not failed); different market tests require different evidence/time horizons. Never auto-renew or charge a customer without authorization.

Useful commands:

```powershell
py -3 -m botfarm site-demo --niche "local cafe"
py -3 -m botfarm site-demo --niche "independent tutor"
py -3 -m botfarm lead-list
py -3 -m botfarm launch-queue
py -3 -m botfarm expansion-report
```

Open the `index.html` produced inside `output/expansion_wing/website/<id>/` in a browser. This is **not hosted**. GitHub Pages' terms say it is not intended for hosting a commercial e-commerce business; choose hosting based on explicit commercial allowances, fees, custom domains and form requirements. Do not assume a platform offers perpetual free commercial hosting.

## 5. What a real fully automated selling operation would need later

The remaining missing links are **not merely another AI model**:

- **Creator publishing:** your TikTok/YouTube channel, 2FA, compliance with age/monetization requirements, OAuth and official publishing/analytics API rights, originality and platform disclosure review. Drafts cannot be uploaded without a supported, authorized integration.
- **Digital product store:** a legitimate verified account, supported seller API or other allowed publishing mechanism, payout setup directly on the platform, refund/delivery rules, tax responsibilities, and authenticated transaction receipts. No sales are verified in this release.
- **Agency workflow:** a CRM with consent and status, email provider authorized by you, truthful opt-out handling, client contracts and approvals, actual fulfillment, approved hosting, invoicing/payments. The farm currently makes local demos and **unsent** emails only.
- **AI quality control:** fact checking, originality and copyright clearance, visual quality, audio usage licenses, accessibility, protection against false advertising and deceptive endorsements. No generated content can be trusted solely because a model produced it.
- **Scheduling/accountability:** durable background worker on a laptop that remains on; local crash recovery, audit and dedupe; verified metrics integrations. External account operations must not be simulated as success.
- **Costs:** $0 upfront software is possible; computer, internet, electricity, payment processing, subscriptions, paid AI inference, hosting, domains, and marketplace/platform fees may still apply.

## 6. Windows setup and troubleshooting

1. Keep your **existing** `zero_cost_bot_farm` folder open in VS Code. Do not overwrite the saved `data/` or `output/` directories. Close old dashboard terminals before install.
2. Download `operation_billion_ALL_UPGRADES_v0_7_ONE_ZIP.zip` from the response. Leave it in the Windows `Downloads` folder **without manually extracting it**.
3. Run the one-paste PowerShell command supplied with the ZIP. Its installer verifies SHA256 for each patch file, asks for confirmation, copies a whole-project backup, overlays only code/docs/tests, then runs the full offline unit tests and evidence audit. Any failure rolls back code changes.
4. On success run `py -3 -m botfarm doctor`, then `py -3 -m botfarm expansion-run`, and open the output folder. `start_windows.bat` starts the research/autopilot worker and dashboard. The laptop needs to be running; overnight jobs are not performed while it is off.
5. Install **only** the optional tools you actually need, from their official distributions, after checking resources and licenses. Your HP laptop's 512 GB SSD size does **not** reveal its GPU/RAM. Without FFmpeg the scenes, captions and static websites still work.
6. If the automated verification fails, **do not delete the backup**. Send the terminal output for the exact failure; do not try to bypass tests.

## 7. Permissions and truthful scorekeeping

- **GUILTY →** reject and research/submit a different compliant local method. No unsafe action executes.
- **NOT GUILTY →** run its permitted **local** sample work. External upload, outreach, checkout, payment or account creation are **not** authorized by this court verdict.
- **Metrics:** no invented views, subscribers, buyers, orders, payouts or commissions. Store original links and timestamps for real trials. The present manual records remain user-reported and not independently verified.
- **After 7/14 days:** review evidence of real exposure and conversions; distinguish no launch, insufficient sample, poor engagement, and real profits. Pivot meaningfully rather than copy the same rejected strategy.
- **AI suggestions:** untrusted research; never automatically execute arbitrary code from found GitHub repositories or bypass content/API restrictions.
