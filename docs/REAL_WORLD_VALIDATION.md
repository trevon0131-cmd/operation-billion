# Two-lane validation: what constitutes real evidence

## Lane A — Digital storefront
1. A court-approved, original, inspected file = LOCAL DRAFT ONLY.
2. A manually published listing with a genuine public URL = USER-REPORTED LAUNCH; not independently confirmed.
3. Views/clicks/sales/refunds are USER-REPORTED measurements unless future official API access supplies actual events.
4. 7 days + at least 100 views + no clicks = early LOW_ENGAGEMENT; 14 days without positive net return = LOW_RETURN or INCONCLUSIVE. A promising actual response gets additional testing.
5. Price hypothesis is not a claim of revenue. Record net of costs and fees. No real storefront controls connected.

## Lane B — Local businesses
1. A real prospect requires a manually supplied actual public business website, not scraped private Google Maps entries.
2. Evidence packet is created only when a completed NOT GUILTY service case exists.
3. Unsent proposals never count as outreach. A user explicitly records CONTACT_RECORDED after genuine outreach.
4. A 14-day period without a reported reply flags a review of another SERVICE approach. It does not imply a poor or defective business, or authorise another unsolicited message.
5. Customers, contracts, payments and client outcomes must be truthfully supplied; never automatic claims.

## Hard barriers
Court approval != platform permission. No autonomous publishing, payment/identity verification, mass outreach, bypassing website rules, fake traffic, fake testimonials or fake sales. Testing is evidence-gathering, not a promise of income.

## Suggested next integrations after account setup
- Official OAuth permission and restricted API adapter where product creation is supported by actual current API documentation.
- Read-only official sales metrics import with order-ID deduplication and refund handling; never invent purchases.
- Service invoicing and buyer communications only after clear individual authorization and integration review.
- Safer HTML-to-PDF export for local-business proposals after you confirm Windows dependencies; not installed by default.
