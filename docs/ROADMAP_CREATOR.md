# Creator and B2B Expansion — Roadmap beyond v0.7

## Delivered in v0.7 (offline)

- 13 new income research method hypotheses (26 -> 39), compatible with v0.6 evidence, court and lifecycle architecture.
- Curated 14-project GitHub tool registry with license/free caveats, no cloning/execution.
- Two automatic local builders: original video storyboards + PNG slides + SRT; original mobile HTML/CSS sites + service packets.
- Optional FFmpeg MP4, if found; optional local Ollama script headings with strictly validated JSON response.
- Autopilot integrated. Two bounded local demo experiments per day; audits and deduplication.
- Current public Google Trends match where truly relevant, otherwise an explicitly non-trending evergreen idea.
- Windows patch packaging, verified tests and compatibility check; no credentials in package.

## Not delivered and why

- Text-to-cinematic video with live stock assets: needs substantial GPU/model installation or separately authorized external providers and commercial media licenses.
- YouTube/TikTok publishing: requires users' accounts, OAuth/platform access, content eligibility, and verified permission to upload.
- Gmail sending: requires an authenticated authorized sender and CAN-SPAM details, consent/opt-out; in this version drafts remain UNSENT.
- Google Maps business scraping: terms and licensing issues; no scraping or bypassing rules.
- Fully hosted commercial websites: user/client hosting provider and permission; there is no authenticated, approved deployment destination yet.
- Genuine seller analytics and revenue verification: seller APIs and payment receipts not yet connected.
- Fully self-reprogramming AI with arbitrary GitHub repo execution: would be unsafe/unverifiable; new code additions must be reviewed and tested.

## Practical follow-up milestones

1. Confirm Windows installer, dashboard and generated PNG/HTML files pass on laptop.
2. Measure RAM/GPU; install FFmpeg for MP4. Optional Ollama if model runs acceptably.
3. Validate a small set of original video subjects and website service demos with real humans.
4. Connect a single approved marketplace or video channel and a legitimate business email inbox via authorized integration.
5. Add verified metrics read-only and client-outreach permission logging. Only then reconsider supervised upload/send automation.
6. Compare results across categories and pivot at the right 7/14-day thresholds, not purely on viral views.
